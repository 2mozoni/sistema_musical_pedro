🎵 Projeto Front-End: Sistema Musical

Este repositório contém a aplicação web desenvolvida como atividade prática final. O projeto consiste em uma interface responsiva composta por 5 telas interconectadas, estilizadas de forma centralizada utilizando variáveis CSS no :root.


🖥️ Estrutura das Telas

O projeto contém as 5 telas solicitadas, totalmente navegáveis entre si:

login.html – Tela de autenticação inicial com comentário dos integrantes no topo do código.

index.html – Menu principal / Dashboard de navegação do sistema.

cadastro_artista.html – Formulário de cadastro do criador (artista / autor).

cadastro_musica.html – Formulário de cadastro da obra (música / item).

listagem_musica.html – Tabela/grid de exibição e listagem das obras cadastradas.

🎨 Estilização Centralizada

Todo o visual do sistema é gerido por um único arquivo CSS (styles.css / style.css), utilizando variáveis CSS (:root) para padronizar a paleta de cores, tipografia e espaçamentos do tema escolhido.

📱 Responsividade & Validação

Cross-device: Layout adaptado para visualização em computadores e dispositivos móveis (Mobile-First / Flexbox / Grid).

Validação de Formulários: Campos obrigatórios configurados com HTML5 (required) para impedir envio com dados em branco.
